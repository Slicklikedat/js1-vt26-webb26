# JavaScript 1 – WEBB26

Detta repository används i kursen **JavaScript 1** för klassen **WEBB26**.

## Om kursen

Kursen fokuserar på grunderna i JavaScript och hur språket används för att skapa **interaktiva och dynamiska webbsidor**. Under kursen arbetar vi bland annat med:

- JavaScript-syntax och programmeringslogik
- variabler, villkor, loopar och funktioner
- DOM-manipulation
- interaktivitet i webbsidor
- felhantering
- grundläggande arbete med dynamiska hemsidor
